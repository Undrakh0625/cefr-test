Анхааруулга:

Энэ бол түвшин тогтоох шалгалт, IELTS/TOEFL-ийн оронд биш. Таны англи хэлний ерөнхий мэдлэгийг CEFR стандартын дагуу сургалтын дотоод хэрэгцээнд баримжаалан тодорхойлно.

Олон улсын CEFR стандарт (A1 – C2)

Англи хэлний түвшингээ бодитоор тодорхойл

Энэхүү систем нь таны дүрэм, үгсийн сан, унших болон сонсох чадварыг 60 асуулттай сангаас шүүн шалгаж, CEFR-ийн 6 түвшний аль шатанд байгааг тодорхойлно.

1. Дүрэм ба Үгсийн сан

Нэг сонголт, хоосон зай нөхөх, өгүүлбэр залгах

2. Унших чадвар

Эшлэл уншиж гол санааг ойлгох асуултууд

3. Сонсох чадвар

1.0x болон 0.8x хурдаар аудио сонсох даалгавар

Шалгалтын санамж:

  • Заавар Монголоор, шалгалтын асуултууд Англи хэлээр байна.
  • Асуултын дараалал болон хариултын хувилбарууд оюутан бүрт санамсаргүй холигдоно.
  • Тухайн түвшний асуултын 70%-иас дээш зөв хариулбал тухайн түвшинг давсанд тооцно.
  • Шалгалт дуусмагц дүнгийн хуудас таны имэйл болон багшийн системд автоматаар илгээгдэнэ.

Google Apps Script суулгах 4 алхамт заавар

  1. Google Drive дээрээ шинэ Google Sheet үүсгэнэ.
  2. Дээд цэснээс Extensions → Apps Script руу орж, доторх кодыг устгаад доорх кодыг бүхлээр нь хуулж тавина.
  3. Deploy → New deployment дарж, төрлийг Web app болгоно. Execute as: Me, харин Who has access: Anyone болгож сонгоно.
  4. Зөвшөөрөл асуух цонхонд Advanced → Go to ... (unsafe) → Allow дарж имэйл илгээх эрхийг зөвшөөрнө. Гарч ирсэн Web App URL-ийг хуулж index.html доторх DEFAULT_GOOGLE_SHEETS_URL-д оруулна.
function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);

    // 1. Хэрэв хүснэгт хоосон бол толгой гарчиг (Header) автоматаар үүсгэнэ
    if (sheet.getLastRow() === 0) {
      sheet.appendRow([
        "Огноо",
        "Овог нэр",
        "Анги/Бүлэг",
        "Имэйл",
        "Горим",
        "CEFR Түвшин",
        "Нийт оноо (%)",
        "Зөв / Нийт",
        "Дүрэм ба Үгсийн сан",
        "Унших",
        "Сонсох",
        "Зарцуулсан хугацаа",
        "IP хаяг",
        "Төхөөрөмж / Хөтөч"
      ]);
      sheet.getRange(1, 1, 1, 14).setFontWeight("bold").setBackground("#f3f4f6");
    }

    // 2. Шалгалтын үр дүнг мөр болгон нэмэх
    sheet.appendRow([
      new Date().toLocaleString("mn-MN", { timeZone: "Asia/Ulaanbaatar" }),
      data.name || "",
      data.classGroup || "",
      data.email || "",
      data.mode || "",
      data.level || "",
      data.totalPercent + "%",
      data.correctCount + "/" + data.totalQuestions,
      data.grammarScore || "",
      data.readingScore || "",
      data.listeningScore || "",
      data.duration || "",
      data.ipAddress || "Тодорхойгүй",
      data.deviceInfo || ""
    ]);

    // 3. Оюутны имэйл рүү дүнгийн хуудас автоматаар илгээх
    if (data.email && data.email.indexOf("@") > -1) {
      sendResultEmail(data);
    }

    return ContentService
      .createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ status: "error", message: err.toString() }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
